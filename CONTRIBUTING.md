# Contributing to SymBot

Thanks for your interest in improving SymBot. Contributions of all kinds are
welcome — bug fixes, features, documentation, and ideas.

## How to contribute

- Open an issue to report a bug or propose a feature before starting large work,
  so we can discuss the approach.
- For code changes, open a pull request describing what it does and why.
- Keep pull requests focused. Smaller, self-contained changes are easier to
  review and merge.
